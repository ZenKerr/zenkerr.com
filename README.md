## Usage

Open in [browser](https://zenkerr.com).

### From Source

To run the website from source, ensure you have **Node.js** and **bun** installed.

1. Clone the repository:

   ```shell
   git clone https://github.com/ZenKerr/zenkerr.com.git
   cd zenkerr.com
   ```

2. Install dependencies:

   ```shell
   bun install
   ```

3. Start the development server:

   ```shell
   bun run dev
   ```

Also, you can create a static build:

```shell
bun run build
```
